- Perfil cardiovascular (atlético, sedentário, hipertenso controlado, cardiopata) é definido manualmente pelo fisio; anamnese só lembra.
- Teto de FC (Gellish 207−0,7×idade: 75/70/65%) aparece no prontuário e para o paciente (painel + check-in).
- Nunca citar marcas de equipamento; dizer "monitor cardíaco (cinta, relógio ou pulseira)".
- Sempre prever caminho sem monitor: oxímetro de dedo (FC + SpO₂).
- Plano completo em docs/modulo-cardiovascular.md.

# Insight signal architecture

- Smart insights live in `src/components/dashboard/insights/` backed by scoped RPCs (`get_patient_churn_risk`, `get_patient_load_alerts`, `get_reassessment_due`, `get_steps_phase_overview`, `get_reactivation_candidates`, `get_clinic_therapist_stats`, `get_clinic_funnel`, `get_clinic_patient_concentration`, `get_patient_adherence_scores`); all deterministic, clinic/solo scoped (solo = clinic_id IS NULL), no AI credits. Pain and readiness signals come from readiness check-ins only — pain diary and internal messages are never metric inputs (few patients use them). Realized sessions count from completed slots OR same-day session notes (`synthesizeNoteSessions`), so unclassified agendas never empty the metrics; flare-up is the latest check-in pain ≥ 2 above the 30-day average (3+ check-ins). Discharge prediction blends check-in pain (40), STEPS phase (30), 4-week load progress (15) and current readiness (15).

# Studio rules
- Hospitality display phrases use fact-scoped `hospitalityDisplayTerms`, and repeat/stack blocks preserve the whole phrase with container sizing; contact labels use `studioSiteLabel` without tracking parameters, preventing generic verbs and URL walls while preserving saved destinations.
- Hook library rotation uses canonical `hookSignature` identities and hook-only fresh-first streams in the director; hospitality preserves the active theme's library before factual focusing, and visible single hooks are recorded rather than spare reservations, so repertoire coverage survives route rewriting and rapid batches without changing saved kits.
- Studio kinetic art uses its own frame-sized section, never the landing's viewport-height sticky statement; manual image dialogs reset their mode/slot on opening and reject replacement of nonexistent slots, preventing off-frame photos and silent swaps across templates.
- Hospitality identity is resolved from declared niche/offer in `studio-pro/businessFit.ts`; `hospitalityContent.ts` supplies scoped stay facts before rendering and the director skips service-result routes, preventing incidental booking software from changing the business model.
- Background-photo lighting shares `photoLight.ts`: opaque, neutral photos and overlay opacity reach zero shade together; snapshots retain settings. Export paints backdrop photos once and uses `photoFilter.ts` pixel fallback when Safari lacks canvas filters, preventing raw foreignObject images from covering shaded pixels. Manual backgrounds reversibly suppress decorative patterns, never foreground identity/text.
- Photo management keeps usage selectors separate from fixed-size actions on narrow screens; deletion confirms first, reports failures, and verifies the returned database ID before changing the gallery or cleaning storage, preventing clipped controls and silent zero-row deletes.
- Product-focused software shots send their actual fact vocabulary to photo affinity; user-declared generic product interfaces may illustrate product education without fake clinical topics, while specific caption/procedure restrictions remain scoped.
- Official external asset mirrors resolve by exact source URL in `brand.ts`, including legacy export snapshots; reuse existing bundled official assets because an image may display cross-origin but fail SVG/canvas export without CORS.
- Product copy splits declared exam enumerations into individual facts with scope retained in support; display vocabulary never uses sentence fragments. Touch PNG delivery prepares the shared raster first and requests a fresh gesture for file delivery, because Safari expires activation during rendering.
- Software product education shares `studio-pro/productFocus.ts` and counts carousel groups once; use only declared/scoped capabilities (canonical owner packages), preserving media metadata and never interpreting symptoms as product features.
- Client-brand commercial prioritization and audience hook libraries share `studio-pro/commercialPriority.ts`; rank only declared audience/offer facts locally and never overwrite saved kits or infer efficacy/conversion.
- Studio copy lists use the shared `listCoherence.ts` guard at final voice review and rendering; semantic deduplication keeps original complementary arguments without padding or modifying media metadata.
- Studio list editing targets the text leaf rather than the icon-bearing row and rejects positional snapshots with mismatched slot counts; this preserves icons and prevents stale edits shifting into labels after deduplication.
- Studio PNG exports must always use the shared static export surface in `exportImage.ts`; one pipeline prevents preview/download drift across individual, batch, carousel, thumbnail, and gallery flows.
- Static exports rasterize outset box shadows in place before SVG capture and preserve inherited text alignment; WebKit foreignObject otherwise shifts shadows to the right and detached text loses its centering.
- In `exportImage.ts` canvas repaint, only photos (acervo/`data-studio-photo` or user-inserted) may paint as backdrop; every other `<img>` (logos, marks, avatars) defaults to foreground because it sits above opaque surfaces in the DOM — painting it as backdrop lets the rasterized card cover it (empty tweet avatar bug).
- Official Studio screenshots use `photoPolicy` and exact canonical differential mappings, never `studio_photos` or fallback matches; this preserves quota-free framing and semantic fit.
- User-inserted Studio images are DOM layers on the shared art surface: background insertions stay behind text with reduced brightness, while composition insertions remain foreground, movable, resizable, and export through the same PNG pipeline.
- Studio cross-field copy coherence must be enforced by the shared final voice guard and shared block support picker; one global gate prevents brand- or layout-specific repetition and dangling titles.
- Studio acronym explanations and legacy loss-connector repairs must use shared contextual copy normalization after the final voice guard and in ecosystem construction; one idempotent rule keeps formats readable without altering media metadata.
- Device mockups in Studio arts get their screen text from `mockScreens.ts` (headline keyword → topic theme for the owner brand; deduplicated feature labels, never audience names, for client brands) so the illustration always matches the art's promise.
- Studio photo choice treats platform terms in the user's caption as a declared topic (`captionTopics` in `photoMeaning.ts`); a declared match narrows rotation to near-top photos so captioned prints win without AI.
- Aliv.iA Studio CTAs pass through `studio-pro/ctaAudience.ts` in `finish`: patient-only calls (autoavaliação) never close pro/clinic arts and pro-only calls never close patient arts; pro/clinic arts also drop patient-only titles (never emptying a list), because the shared kit mixes both audiences.
- Studio audience voice (patient vs. pro CTA/title alignment) is decided by the audience tree root (`audienceRootId`), and `# SECTION` headers in format insights scope lines to that audience; free-text word matching only applies when no root/section exists, because descriptions mention other actors.
- Studio captions use rendered copy at click/download/save time; legacy content-only paths keep only related proofs and omit standalone objections so captions cannot contradict the art.
- Natural voice preserves complete source sentences; factual and clinical copy bypasses rhetorical rewriting, and official Aliv.iA audience pools cannot be overridden by free brand-level routes because those can leak another feature or audience.
- Device mockups (notebook/tablet/phone) show only real system prints via `pickScreenPhoto` (usage Produto + screen caption) as a foreground layer; without prints they fall back to `mockScreens.ts`, so portraits never appear inside a screen.
